Выбран TVmaze API.
Не требует API-ключа.

Производится:
Поиск сериалов по названию (на английском языке),
Получение информации: название, язык, жанры, рейтинг, постер, краткое описание
Добавление шоу в избранное, отображение избранных на отдельной странице

Реализованный сценарий Room
Избранное (Favourites)
Таблица:favourite_show 
Хранимые поля: id, name, language, genres, rating, imageUrl, summary 
Функционал:
    - Добавление шоу в избранное (иконка сердца на детальном экране)
    - Удаление из избранного (повторное нажатие)
    - Отдельный экран «Избранное» со списком сохранённых шоу
    - Данные сохраняются после перезапуска приложения
